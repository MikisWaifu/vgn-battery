### Keychron 与多鼠标显示

- 加入 MikisWaifu 的 Keychron Ultra-Link 接收器、M5 / M6 8K 协议适配，严格区分其 64 字节接口与原有 VGN 协议；型号缓存按接收器隔离并定期重新识别。
- **固定显示**：选择一只鼠标，只显示它的电量，断开时保留灰色目标。
- **轮换显示**：一个托盘电池图标按时间轮换不同鼠标。
- **平铺显示**：每个当前受支持设备显示一个托盘电池图标，点击查看对应详情。
- 主窗口与右键菜单均可选择模式、固定目标、查询间隔和轮换间隔。

设备按 USB 电量接口区分；同一物理鼠标若同时提供有线和接收器通道，可能列出两项。程序不会在缺少可靠共同标识时猜测合并。

### 默认值与通知

- 电量查询默认改为 **30 秒**，可选 5 / 15 / 30 / 45 / 60 / 120 秒。
- 轮换图标独立计时，默认 **5 秒**，可选 3 / 5 / 10 / 15 秒；切换图标不会额外查询硬件。
- 打开窗口和设备插拔立即请求刷新。单台设备读取失败不影响其它设备；每台设备独立处理低电通知。
- 轮换只切换托盘图标，已打开的详情保持原鼠标，避免读数随图标切换。

### 下载与验证边界

先从托盘退出旧版，再解压运行 **VgnBattery-1.1.0-win-x64.zip**。Windows x64 自包含免安装，设置继续保存在当前用户的本地数据目录。

**101 项离线检查通过**，覆盖协议、设备识别、多设备状态、固定/轮换/平铺、历史读数隔离、设置和低电通知等行为。另有 **11 项模拟托盘集成检查通过**，使用模拟设备验证实际托盘图标的创建、切换和释放，未与真实鼠标通信。模拟检查不能替代每个鼠标组合的实机测试。

维护者早期单设备版本的 F2 Pro Max 接收器实机记录仍保留；Keychron M5 接收器实测来自贡献者 MikisWaifu，维护者尚未复测 Keychron 或多鼠标组合。有线、M6、休眠恢复和长期续航仍需更多反馈。
