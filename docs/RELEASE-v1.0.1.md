修复 **VGN 蜻蜓 F2 大师版 GT** 无法被识别的问题。

### 变化

- 增加 `391D` 厂商扫描，以及 F2 Master GT 的 `391D:102D` 2.4G 接收器、`391D:1032` 有线接口。设备编号和电量格式已核对官方网页驱动，仍需 GT 用户实机验证。
- 校验电量回复的成功状态，避免把错误回复中的数据当作电量。
- 新增右键“导出设备信息”和 `--diagnose`：只读枚举全部 HID 接口，导出 VID/PID、产品名称、用途和报告长度，不包含设备路径或序列号，方便继续适配。

### 更新

先从托盘右键退出旧版，完整解压 **VgnBattery-1.0.1-win-x64.zip** 后运行新版。若旧程序仍在后台，重复打开会激活旧实例。

Windows x64 免安装，自带运行环境。已通过 **50 项离线检查**；GT 实际电量与厂商驱动是否一致，仍需用户反馈。F2 Pro Max 的原有实机验证保持有效。
