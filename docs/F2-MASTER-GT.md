# F2 大师版 GT 适配记录

v1.0.0 在扫描阶段仅保留厂商编号 `3554` 和 `373B`，因此无法发现使用 `391D` 的 F2 Master GT 接收器。此时界面显示默认的“鼠标电量”和“未发现受支持的 USB 鼠标”，尚未进入电量查询。

## 官方协议依据

2026-11-15 静态检查 [VGN 官方网页驱动](https://drive.vgnlab.com.cn/) 的公开客户端资源：

- [index-BfN6tzNB.js](https://drive.vgnlab.com.cn/assets/index-BfN6tzNB.js)
- 该资源文件 SHA-256：`2dc306331d30f874eec8a006f975ef5cac3ed2f18d3bef58e5dd089dc8d5cd5f`

其设备表将以下两项标记为 `Dragonfly F2 MasterGT`，由 `vgn-y2` 电量控制器处理：

| 连接 | VID:PID | Usage Page / Usage | Report ID |
| --- | --- | --- | --- |
| 2.4G 接收器 | `391D:102D` | `FF02:0002` | `08` |
| USB 有线 | `391D:1032` | `FF02:0002` | `08` |

控制器的电量命令编号为 `04`。WebHID 分开发送 Report ID 和 16 字节数据；Windows 完整 HID 帧仍为 17 字节：

```text
08 04 00 00 00 00 00 00 00 00 00 00 00 00 00 00 49
```

响应包含 Report ID 时，字节 `[2] == 0` 表示成功，`[6]` 为百分比，`[7] == 1` 为充电标志，`[8..9]` 为大端毫伏值。完整 17 字节的和模 256 为 `55h`。

v1.0.1 只增加这两个型号标识，并继续要求 `FF02:0002` 和输入/输出各 17 字节；其它 `391D` 设备不会被自动发送电量命令。不复制或分发官方 JavaScript，也不调用设置、配对或固件更新命令。

## 验证边界与反馈

以上为官方客户端的静态协议证据，尚不是这只 GT 的实机验收。请先从托盘退出旧版，再启动 v1.0.1，切换到 2.4G 并移动鼠标。

若仍读不到，请右键选择“导出设备信息”，将生成的 JSON 附在问题反馈中。报告只包含描述符元数据及脱敏失败阶段，不包含设备路径和序列号，也不向设备发送报告。不要用旧 `--enumerate` 产生的原始 `devices.json` 直接公开反馈。
