VGN Battery 首个公开版本：在 Windows 任务栏右下角查看鼠标电量，无需一直打开厂商驱动。

### 下载与使用

下载下方 **VgnBattery-1.0.0-win-x64.zip**，完整解压后双击 `VgnBattery.exe`。包内自带运行环境，无需另装 .NET，无需管理员权限。`SHA256SUMS.txt` 用于校验下载文件。

### 功能

- 每 5 秒通过 USB 接收器或数据线查询电量，自动识别型号。
- 托盘电池可选显示数字；正常读数绿色，断开或休眠灰色。
- 置顶详情窗口、可拖动区域、统一深色菜单与设置卡片。
- 开机启动、自定义低电阈值、Windows 通知及测试通知。

### 支持范围

已在 **Windows 11 x64 + VGN F2 Pro Max 2.4G 接收器**上实测。F1、R1、MAD R 和部分 ATK 的已知接口按公开协议登记，尚未由本项目逐台验证；不代表全部 VGN 型号都能使用。当前版本不读取蓝牙电量。

发布前通过 **43 项离线检查**，支持列表、使用说明和验证边界见 [README](https://github.com/zerobeyondlogic/vgn-battery#readme)。MIT 开源，欢迎反馈兼容性问题。
