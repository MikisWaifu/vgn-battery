### 降低内存和后台开销

- 关闭程序单文件内部压缩，ZIP 仍压缩，保持 Windows x64 免安装且无需另装 .NET。
- 第二次启动改用事件唤醒，移除每 300 毫秒检查一次的计时器。
- 隐藏窗口和菜单时跳过设置同步；缓存任务栏主题，每轮电量查询完成后统一更新托盘状态。
- 补充忽略规则，避免临时配置、设备报告副本、环境文件、签名文件和调试转储误入仓库。

相同双设备模拟条件下，关闭内部压缩后，30 秒采样的工作集约从 **128 MiB 降到 62 MiB**，私有内存约从 **54 MiB 降到 14 MiB**。这是短时模拟，不能代替真实设备长期测量，详见[测量说明](https://github.com/zerobeyondlogic/vgn-battery/blob/v1.1.1/docs/PERFORMANCE.md)。

代价是解压后的 EXE 约 **111 MiB**；下载 ZIP 约 **45 MiB**，比 v1.1.0 增加约 1 MiB。

### 更新与验证

先在托盘右键选择“退出”，再完整解压新版并运行 `VgnBattery.exe`。原有设置继续保留；已开启自启动的用户运行新位置的程序后会更新启动路径，新用户仍默认关闭自启动。
