### 修复下拉菜单崩溃

合入 MikisWaifu 的 [PR #3](https://github.com/zerobeyondlogic/vgn-battery/pull/3)。v1.1.0 / v1.1.1 在详情窗口切换显示方式等下拉选项时，菜单可能在自身点击处理尚未结束时被释放，触发 `ObjectDisposedException` 并退出。现在会等点击流程结束后再释放菜单。

### 其它设备电量概览

采纳 [Issue #4](https://github.com/zerobeyondlogic/vgn-battery/issues/4)：在更新时间下方列出其它当前设备的名称、连接方式和电量。固定、轮换和平铺三种模式都可查看，顶部正在查看的设备不会重复列出。

- 有效新读数显示百分比，真实 0% 仍显示 0%。
- 历史电量置灰并标注“上次读数”；尚未成功读取的设备显示“未响应”。
- 长名称省略，保留连接方式，便于区分相同型号以及同一物理鼠标的有线和接收器接口。
- 窗口随设备数量增高，屏幕空间不足时可滚动；后台刷新保留已拖动的位置。

列表复用已有电量读数，不增加查询或计时器。默认查询仍为 **30 秒**，v1.1.1 的低内存打包方式和后台唤醒优化均保留。

### 更新与验证

先在托盘右键选择“退出”，再完整解压 **VgnBattery-1.1.2-win-x64.zip** 并运行 `VgnBattery.exe`。原有设置继续保留；已经开启自启动时，启动路径会更新为当前运行位置，新用户默认关闭自启动。

本版通过 **111 项离线检查**（含其它设备列表状态）、**11 项模拟托盘集成检查**、**9 项真实 WinForms 菜单生命周期检查**和 **5 项窗口布局检查**。菜单测试实际执行选择、关闭重入和释放后重开；旧同步释放代码会在首次点击重现同栈异常，修复后通过。布局检查覆盖超屏滚动、移除列表后收回空间，以及刷新保持位置和滚动进度。

另在本机测试窗口实际点选了固定、轮换和平铺模式，并检查 150% 系统缩放下的导出预览。以上菜单和布局检查使用模拟设备，不代表每种鼠标组合都已实机验证。

维护者已在 2026-11-17 通过 v1.1.1 的 VGN F2 Pro Max USB 有线连接读到 **100%**；此前的 2.4G 接收器记录也保留。Keychron M5 接收器的实测来自贡献者，维护者尚未复测 Keychron 或多鼠标组合；GT、其它型号和长期运行仍需更多实机反馈。
